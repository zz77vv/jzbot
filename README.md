# LedgerFlow

从零重新设计的 Telegram Business 智能记账与客户账本系统（基于 **aiogram 3** + 独立不可变流水日志数据库）。

## 核心特性

* **全新 aiogram 3 异步引擎**：完全独立于旧版技术栈，原生支持 Telegram Business 私聊记账、富文本 HTML 卡片与即时文件导出。
* **更顺手的私聊记账体验**：
  * `+100` / `+100.5 货款`：入账（支持附带备注）
  * `-50` / `-50.5 结账`：出账（支持附带备注）
  * `撤销` / `撤` / `-undo`：一键冲正撤销该客户最近一笔有效入账/出账
  * `/` / `账单` / `查账`：发送 HTML 排版对账单（含别名、标签、余额、累计收支与最近 8 条流水）
  * `//` / `清账` / `结清`：余额清零
* **全面升级的财务总控台（`/start`）**：
  * **财务总览与周期报表**：今日 / 本周 / 本月 / 全部汇总、资金净敞口、Top 5 存款与欠款排行
  * **一键导出 Excel / CSV**：支持导出全量客户余额表、全量流水表、单客户个人对账单（带 UTF-8 BOM，Excel 直接打开不乱码）
  * **客户 CRM**：自定义别名（不怕客户改名）、多标签分组、按标签筛选与定向通知、后台直接补录调账、一键撤销/结清、静默定位聊天
  * **可靠性保障**：0.1 USDT 整数运算无浮点误差、SQLite WAL + FULL 同步、回执自动退避重试与连接故障自动切换、后台一键热备份与账本健康体检

## 无损数据迁移

支持从旧版 V2 `ledger.db` 或 V4 `jzbot.db` **只读迁移**到全新的 `ledgerflow.db`，并自动逐客户核对余额与流水总数：

```bash
python tools/migrate.py /path/to/old.db /path/to/ledgerflow.db
```

## 运行与测试

```bash
python -m pytest -q
python -m ledgerflow
```
